# LubenWatches

Sitio público de información de LubenWatches, una aplicación Android con complemento Wear OS de la marca Lubenware. País de operación: México.

Contacto: [support@lubenware.com](mailto:support@lubenware.com).

La aplicación está dirigida a personas de 13 años o más, incluidos adolescentes. Su distribución pública inicial está prevista en México; esta información no anuncia su habilitación en producción de Google Play.
